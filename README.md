# Messy Mashup Genre Classification

Classifying the dominant genre of noisy, multi-stem audio "mashups" from mel-spectrogram
features. Built for the **Messy Mashup Genre** Kaggle-style competition.

**Metric:** Macro F1 between predicted and actual genre label.

## Problem

Each test sample is a ~30-second audio mashup: stems (drums, vocals, bass, other) drawn from a
song of a target genre, mixed together at random weights and layered with ESC-50 environmental
noise at random intensity. The task is to predict the dominant genre — one of `blues`,
`classical`, `country`, `disco`, `hiphop`, `jazz`, `metal`, `pop`, `reggae`, `rock` — for each
mashup in the held-out test set.

## Approach

1. **EDA** — indexed all genre/song/stem directories, verified all four stems (`drums`, `vocals`,
   `bass`, `others`) exist per song, counted available ESC-50 noise clips.
2. **Feature engineering** — 30s audio loaded/padded to a fixed length, converted to a log-mel
   spectrogram (128 mels) plus first and second-order deltas, stacked into a 3-channel
   "image" (mel + Δ + ΔΔ) and per-channel normalized.
3. **Synthetic training data** — since labeled mashups aren't available for training, 6,000
   synthetic mashups were generated by mixing stems from a single song at random per-stem gains
   and layering random-intensity ESC-50 noise, to approximate the test distribution.
4. **Modeling** — four architectures compared on an 85/15 stratified split:

   | Model | Val Macro F1 |
   |---|---|
   | CNN (from scratch) | 0.6261 |
   | CRNN (CNN + bidirectional GRU) | 0.7373 |
   | EfficientNetV2-S (ImageNet pretrained, transfer learning) | 0.8114 |
   | **EfficientNetV2-S (fine-tuned on real mashup audio)** | **0.8463** |

5. **Pseudo-labeling + fine-tuning** — real (unlabeled) mashup audio was pulled from Hugging
   Face, labeled with the pretrained EfficientNet as a teacher (confidence > 0.5 kept), and used
   to fine-tune EfficientNetV2-S directly on the test-like distribution — the largest single
   jump in validation score.
6. **Inference** — 3-model weighted ensemble (mashup-finetuned EfficientNet 0.60, pretrained
   EfficientNet 0.25, CRNN 0.15) with:
   - Deterministic offset test-time augmentation (5 passes over different 30s windows per song)
   - Confidence softening (power 0.85) to reduce overconfident predictions
   - Class-frequency debiasing to correct for genre imbalance in the combined predictions

   All runs tracked with Weights & Biases.

## Repo structure

```

├── README.md

```

> Data (`genres_stems/`, `ESC-50-master/`, `mashups/`, `test.csv`) is **not** included in this
> repo — download it from the competition page and place it under a local `data/` folder
> (already excluded via `.gitignore`), or point the notebook's file paths to wherever you have it.
> Model checkpoints are pulled from/pushed to Hugging Face Hub during training; you'll need your
> own W&B and HF tokens to reproduce logging and checkpoint uploads.

## Setup

```bash
pip install -r requirements.txt
jupyter notebook notebook/music_genre_classifier.ipynb
```

## Results

Best model: **EfficientNetV2-S fine-tuned on real mashup audio**, val Macro F1 ≈ **0.8463**.

Final 3-model ensemble with TTA, softening, and debiasing: **Public Leaderboard Macro F1 ≈ 0.825**.
